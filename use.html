💡 はじめに

当掲示板は、パスワード不要で完全に匿名性を保ちながらリアルタイムチャットを楽しめる次世代の掲示板です。
投稿フォームからコマンドを入力することで、管理作業やカスタマイズが直感的に行えます。

🔑 名前とIDについて (シード値)

投稿時の「シード」は、あなただけの固有のIDを生成するためのパスワードのようなものです。

  • 入力したシード値はそのまま保存されず、高度な暗号化（SHA-256）によってハッシュ化され、その先頭7文字があなたのIDとして表示されます。
  • 同じシード値を入力すれば、いつでも同じIDで投稿できます。
  • 他の人にシード値を知られないように管理してください。

✨ 便利な機能

  • IDのワンクリックコピー: 投稿一覧の「名前」の部分をクリックすると、その人のIDを自動でコピーできます。
  • 投稿日時の確認: 投稿番号（No）にマウスカーソルを合わせる（スマホの場合は長押し）と、正確な投稿日時が表示されます。
  • URLの自動リンク: 投稿文や「今の話題」にURLを含めると、自動でクリックできるリンクになります。
  • 過去ログの保護: 名前や色、称号を後からコマンドで変更しても、過去の投稿のデザインは書き換わりません（スナップショット機能）。

👑 権限システムと色

ユーザーには様々な権限ランクがあり、ランクに応じてIDの色が変わります。文字数は一般ユーザーが50文字、権限持ちが500文字までです。

権限名 IDの色 概要
Root Owner 非表示（赤名） マスター管理者（KF81wqJ）。すべてのコマンドが使用可能。
Owner 非表示（赤名） 運営。HTMLタグの利用や、青IDの投稿制限などが可能。
Summit ダークシアン 上級管理者。ユーザーのBANなどが可能。
Moderator 紫 中級管理者。称号の付与、色の変更、NGワード設定が可能。
Manager 赤 投稿管理者。投稿の削除、クリア、話題の変更が可能。
Speaker オレンジ スピーカー。専用フィルターでの表示対象になります。
一般ユーザー 青 基本の権限です。

🛠️ コマンド一覧

メッセージ欄の先頭に以下のコマンドを入力して送信することで実行されます。

一般向けコマンド

  • /disself : 自分の称号、色、役職をすべてリセットし、一般ユーザー（青ID）に戻ります。（※Owner以上の運営には効きません）

Manager（マネージャー）以上

  • /del [No] : 指定したレス番号の投稿を「削除されました」にします。複数指定可（例: /del 1 3 5）
  • /destroy [文字] : 指定した文字列を含む投稿、または指定IDの投稿を一括で削除します。（/destroy e で全レス削除）
  • /clear : 掲示板のすべてのデータを完全に消去します。
  • /topic [文字] : 「今の話題」を変更します。
  • /max [数] : 掲示板の最大投稿数を設定します。これを超えると自動クリアされます。

Moderator（モデレーター）以上

  • /add [ID] [称号] : ユーザーにピンク色のカスタム称号を付与します。
  • /color [色] [ID] : ユーザーの名前の色を変更します。（例: /color blue ABCD123）
  • /speaker [ID] : ユーザーにSpeaker権限を付与 / 剥奪（/disspeaker [ID]）
  • /NG [単語] : 掲示板のNGワードを追加 / 解除（/OK [単語]）

Summit（サミット）以上

  • /ban [ID] : 指定したIDのユーザー（およびそのIPアドレス）をアクセス禁止にします。
  • /unban [ID] : 指定したIDのアクセス禁止を解除します。
  • /manager [ID] : ユーザーにManager権限を付与 / 剥奪（/dismanager [ID]）
  • /moderator [ID] : ユーザーにModerator権限を付与 / 剥奪（/dismoderator [ID]）

Owner（オーナー）以上【運営】

※OwnerおよびRoot Ownerは、投稿文と「今の話題（/topic）」内でHTMLタグ（<b>や<span style="color:red;">など）を使用できます。

  • /prohibit [分] : 指定した分数の間、一般ユーザー（青ID）の投稿をすべて禁止にします。
  • /permit : /prohibit による制限時間を強制的に解除します。
  • /summit [ID] : ユーザーにSummit権限を付与 / 剥奪（/dissumit [ID]）

Root Owner 専用

  • /owner [ID] : ユーザーにOwner権限を付与 / 剥奪（/disowner [ID]）
